Run the real app on your laptop

About 20 minutes the first time, then one command each time after. You'll end up at http://localhost:8080 with the live Phase 1 page reading from MySQL.

First-time setup

  1. Install the tools

    • Java 17 or newer: Eclipse Temurin from adoptium.net. Check it with java -version.
    • MySQL 8 Community Server from dev.mysql.com/downloads. Write down the root password you choose. Also install MySQL Workbench (it comes with the Windows installer). Or use Homebrew: brew install mysql then brew services start mysql.
    • Git (git-scm.com) and an editor: IntelliJ IDEA Community or VS Code.

  2. Download the project (Phase 1 branch)

    In PowerShell:

    In Terminal:

    git clone https://github.com/DJordan321/Spartan-Club-Central.git
    cd Spartan-Club-Central
    git checkout phase-1-foundation

  3. Create the database and load the 32 sample clubs

    Easiest on Windows: open MySQL Workbench, connect as root, then for each file choose File → Open SQL Script and click the lightning bolt:

    1. database\schema.sql
    2. database\sample-data.sql
    mysql -u root -p < database/schema.sql
    mysql -u root -p club_central < database/sample-data.sql

  4. Create the app's own database user

    It can read and write data but can't drop tables. Pick a password and replace pick-a-local-password below and in step 5. Run this as root (a Workbench query tab, or mysql -u root -p):

    CREATE USER 'club_app'@'localhost' IDENTIFIED BY 'pick-a-local-password';
GRANT SELECT, INSERT, UPDATE, DELETE ON club_central.* TO 'club_app'@'localhost';

Every time you run it

  1. Start the app with your database password

    Run from the Spartan-Club-Central folder. The password lives only in this window, never in a file on GitHub.

    $env:DB_PASSWORD="pick-a-local-password"
    .\mvnw.cmd spring-boot:run
    DB_PASSWORD="pick-a-local-password" ./mvnw spring-boot:run

    IntelliJ alternative: Run → Edit Configurations → SpartanClubApplication → Environment variables → DB_PASSWORD=..., then press Run.

  2. Open the site

    Wait for Started SpartanClubApplication, then open http://localhost:8080. You should see the Phase 1 checkpoint page with 31 active clubs. Press Ctrl+C in the window to stop the app.

  3. Optional: run the tests

    .\mvnw.cmd test
    ./mvnw test

    Expect 30 passing tests (1 MySQL test skipped unless you turn it on; see docs/run-locally.md).

Before a demo: reset the data

In Workbench, run database\reset-demo.sql, then database\sample-data.sql.

mysql -u root -p club_central < database/reset-demo.sql
mysql -u root -p club_central < database/sample-data.sql

If something goes wrong

You seeFix
Access denied for user 'club_app' (using password: NO) DB_PASSWORD isn't set in the window that started the app. Redo step 5 in the same window.
Access denied ... (using password: YES) Wrong password, or step 4 wasn't run. Redo step 4.
Communications link failure MySQL isn't running. Windows: start "MySQL80/84" in the Services app. Mac: brew services start mysql.
Unknown database 'club_central'Step 3 wasn't run.
Schema-validation: missing column Old database. Run DROP DATABASE club_central; as root, then redo steps 3 and 4.
Port 8080 was already in useThe app is already running in another window. Stop it with Ctrl+C.
'java' is not recognizedInstall Java 17+ and open a new terminal window.
./mvnw: Permission denied (Mac)chmod +x mvnw
